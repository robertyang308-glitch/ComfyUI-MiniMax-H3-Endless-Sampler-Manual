# docs

- `chunk_descriptions_guide_basic.md` — writing chunk descriptions for the
  **Endless Sampler** node, where the chunk layout is uniform and comes from
  the node widgets.
- `chunk_descriptions_guide_advanced.md` — writing chunk descriptions for
  **Endless Sampler (Advanced)**, where you also choose a span and an overlap
  for each chunk.
- `_check_chunk_headers.py` — scans a folder tree of prompt files, checks that
  the `#` chunk headers add up, and offers to quarantine or delete the ones
  that do not. Run it from the folder you want to scan.
